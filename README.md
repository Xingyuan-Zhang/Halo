# Halo

Halo is a pretrained whole-cell segmentation model for spatial transcriptomics. The command-line pipeline combines a Xenium DAPI image with a transcript-density pseudo-image and runs the pretrained Cellpose-based Halo model.

The model checkpoint is **not stored in this GitHub repository**. On first use it is downloaded from [XYZ1998/Halo on Hugging Face](https://huggingface.co/XYZ1998/Halo) and then reused from the local Hugging Face cache.

## Installation

```bash
git clone https://github.com/Xingyuan-Zhang/Halo.git
cd Halo
python -m pip install -e .
```

## Run Halo

```bash
halo /path/to/xenium_dataset \
  --out-dir results/halo \
  --mask-format npy
```

Halo searches for DAPI at `morphology_focus/ch0000_dapi.ome.tif` and then `morphology.ome.tif`. It writes:

- `halo_processed.tiff`: normalized DAPI and transcript-density channels;
- `cell_masks.npy` or `cell_masks.tiff`: instance-labelled cell mask.

Useful options:

```bash
# CPU inference
halo DATASET --out-dir results --cpu

# Explicit local checkpoint (no network access)
halo DATASET --out-dir results --model-path /path/to/Halo

# Select a Hugging Face tag or commit and cache location
halo DATASET --out-dir results \
  --model-revision REVISION \
  --cache-dir /path/to/huggingface/cache
```

The input transcript table must expose `x`, `y`, `qv`, and `feature_name` through `spatialdata-io`'s Xenium reader. Large whole-slide images can require substantial RAM and GPU memory.

## Python API

```python
from pathlib import Path
from halo.pipeline import run_pipeline

mask_path = run_pipeline(
    xenium_dir=Path("/path/to/xenium_dataset"),
    out_dir=Path("results/halo"),
)
print(mask_path)
```

To download only the checkpoint:

```python
from halo import download_halo_model

checkpoint = download_halo_model()
```

## Published analysis

The curated scripts used for the main figures are in [`analysis/`](analysis/README.md). The directory includes a figure-to-script manifest and documents inputs that cannot be distributed through GitHub. Representative publication panels generated by these scripts are in [`figures/published/`](figures/published/).

Raw Xenium data, intermediate masks, HPC logs, and model weights are intentionally excluded.

## Model training

The portable Cellpose-SAM training workflow and the published hyperparameters are documented in [`training/`](training/README.md). It supports both the full multi-tissue model and the held-out-tissue experiment from the paper. Training data, disk caches, and checkpoints are excluded from Git.
